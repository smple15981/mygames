# Hearthwild HD-2D

一个使用 Godot 4 开发的原创俯视角混合 HD-2D 游戏项目。

项目目标是把以下体验组合成统一循环：

- 自由采集、制作与基地建设
- 种植、经营与角色生活
- 地图探索、洞穴与区域首领
- 高反馈的动作战斗与装备成长

## 当前阶段

设计规格评审中。首个垂直切片将包含：

1. 一个小型农场基地
2. 一个森林探索与战斗区域
3. 一个洞穴入口和精英敌人
4. 基础采集、背包、制作、种植与近战系统
5. 混合 HD-2D 视觉验证

## 技术方向

- Engine: Godot 4.x
- Language: GDScript
- Camera: Orthographic top-down / three-quarter view
- Visuals: 3D environment + pixel-style 2D characters, VFX and UI
- Assets: only original assets or assets with verified open licenses
