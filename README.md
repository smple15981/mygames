# Hearthwild 2D

Hearthwild 2D 是一个使用 **Godot 4.x + GDScript** 开发的原创俯视角像素生活冒险游戏。项目采用纯 2D 架构，并使用许可证明确的开源像素素材建立统一美术风格。

## 当前画面与最小可玩版本

- 640×360 像素基础视口，放大到 1280×720 时保持清晰像素边缘
- 16×16 开源地表图集按 2 倍显示，对应 32×32 逻辑地图格
- `96×64` 个逻辑地图格，对应 `3072×2048` 像素世界
- 西南农舍区、中央草地区、北部森林区和东部岩石区
- 两座可通行桥梁、连续河流边界和树木/岩石构成的自然地图边缘
- `CharacterBody2D` 玩家、八方向等速移动和四方向移动动画
- `Camera2D` 平滑跟随，鼠标滚轮进行 `0.75～1.50` 范围内的平滑缩放
- 统一脚底锚点和 Y 排序：玩家可自然走到树冠、岩石和房屋屋檐前后
- 房屋墙体、树干、岩石底座、围栏和非桥梁河段具有实体碰撞
- 碰撞仅覆盖接地底座，树冠、屋顶和透明区域不会形成空气墙
- 左上角显示生命、体力和魔力；右上角显示完整世界小地图和玩家位置
- 20 格背包，前 5 格直接作为快捷栏
- 数字键 `1～5` 直接选择快捷栏，`Ctrl + 鼠标滚轮`循环切换快捷栏
- `Tab` 打开或关闭背包与随身制作，并取消当前自动行动
- 背包打开后单人世界暂停，关闭时只释放背包自己的暂停原因
- 出生区固定提供枝条 ×8、碎石 ×7、可采集小树 ×3、可采集岩石 ×3
- 石斧、石镐、木剑和火把的随身制作界面
- 鼠标悬停树木、岩石、拾取物和交互物时显示对应的原创像素光标
- 点击树木或岩石后，角色使用 A* 绕开房屋、围栏、河流和其他实体自动靠近
- 到达交互距离后持续采集，直到资源耗尽或被 WASD、背包、暂停、新目标打断
- 树木必须装备石斧，岩石必须装备石镐；缺少工具时不会移动或消耗资源
- 资源耗尽后生成木材或石头掉落，玩家靠近后自动吸附进入背包
- 背包已满时掉落物保留在地面，不会被错误删除
- Python 仓库合约测试、Godot 无头玩法测试、资源导入、主场景烟雾和图形截图验收

当前已经完成第一个**最小可玩采集闭环**：

```text
靠近拾取枝条与碎石
→ 打开背包制作石斧和石镐
→ 将工具放在快捷栏并选中
→ 鼠标点击树木或岩石
→ 角色自动绕障碍靠近并持续采集
→ 木材或石头掉落
→ 靠近自动拾取进入背包
```

复杂战斗、敌人 AI、多人联机、工具耐久、完整种植、昼夜天气、任务剧情、存档和实际魔法能力仍未实现。

## 获取项目

运行时使用的开源图片已经直接打包进主仓库，**无需初始化 submodule**。GitHub ZIP、普通克隆和普通拉取都应显示真实像素美术：

```bash
git clone https://github.com/smple15981/mygames.git
cd mygames
```

然后：

1. 安装 Godot 4.3 或更新的 Godot 4.x。
2. 在 Godot 项目管理器中导入仓库根目录的 `project.godot`。
3. 运行主场景。

从旧版本更新后，建议关闭 Godot，删除项目根目录下的 `.godot` 缓存目录，再重新导入项目，确保旧场景和纹理不会留在导入缓存中。

## 操作

| 操作 | 键位 |
|---|---|
| 手动移动／立即取消自动行动 | `WASD` 或方向键 |
| 悬停目标 | 移动鼠标，查看状态光标和目标描边 |
| 自动靠近并持续采集 | 鼠标左键点击树木或岩石 |
| 键盘使用当前快捷栏物品 | `J` |
| 镜头缩放 | 鼠标滚轮 |
| 循环切换快捷栏 | `Ctrl + 鼠标滚轮` |
| 直接选择快捷栏 | 数字键 `1–5` |
| 打开或关闭背包与随身制作 | `Tab` |
| 背包打开时优先关闭 | `Esc` |
| 交互预留 | `E` |
| 闪避预留 | 空格或 `K` |

鼠标光标状态：

- 普通箭头：没有可交互目标
- 斧头：已装备石斧，可砍伐树木
- 镐子：已装备石镐，可开采岩石
- 手形：可拾取物
- 齿轮：普通交互物
- 灰色锁定：缺少正确工具
- 红色禁止：目标无法到达

背包或随身制作界面打开时，玩家移动、鼠标交互、持续采集和镜头缩放都会被阻止，单人世界进入暂停。正常游戏中按下任意移动键会立即清空 A* 路径并把控制权交还玩家。

## 世界、寻路与碰撞

世界尺寸由 `WorldLayoutConfig` 统一管理，地图、相机、小地图、A* 和坐标换算不再各自维护重复尺寸。

世界模型采用底座碰撞：

- 树木只阻挡树干和根部，玩家可走到树冠后方并被正确遮挡
- 房屋只在墙体和两侧产生碰撞，农舍和工坊门口保持通行
- 岩石只使用贴合接地部分的碰撞范围
- 围栏只沿底部横梁阻挡，不把透明上半部分算作实体
- 河流在非桥梁区域形成连续实体边界，两座桥同时在物理和 A* 数据中开放
- 草丛、花朵、光点和普通地面碎屑属于装饰，不会意外阻挡玩家
- 鼠标交互区和拾取区使用独立碰撞层，不会推动或卡住角色

`WorldPathGrid` 从 `WorldCollisionRegistry` 动态构建 32×32 A* 网格。树木或岩石耗尽后，它们的碰撞矩形和寻路占用格会立即注销。自动移动连续受阻时最多重新规划两次，仍失败则停止并提示“无法到达”。

地图生成结束后会验证关键路线和安全出生点。未来读取存档时若玩家位置落入实体内部，碰撞注册器可搜索附近最近的安全位置，并在无法局部恢复时回退到农舍安全点。

## HUD 与小地图

- 左上角：生命、体力、魔力及区域文字
- 右上角：固定显示整个 `96×64` 世界的小地图
- 小地图绘制农舍区、草地区、森林区、岩石区、道路、河流、两座桥和农田
- 小地图显示玩家箭头、农舍和工坊等稳定标记
- 小地图直接根据世界数据绘制，不会用第二台摄像机重复渲染世界、灯光和粒子
- 底部中央：5 格快捷栏
- 中下方：缺少工具、无法到达、背包已满等短提示
- `Tab` 覆盖层：20 格背包与随身制作

## 开源美术

主美术来源是 **Ninja Adventure Asset Pack**。项目把实际需要的地表、村庄道具、玩家、小动物和阴影图片以紧凑运行时图集放在：

```text
assets/third_party/ninja-adventure/
```

同时保留：

- Kenney CC0 粒子图片，用于拾取物和局部灯光
- Tabler Icons MIT 图标，用于 HUD
- `assets/original/` 下的原创紧急降级素材、物品图标、交互描边和状态光标

准确来源、固定提交、图集修改方式、实际消费路径和许可证记录见 [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md)。

## 验证

```bash
python -m unittest discover -s tests -v
python tools/validate_project.py .
python tools/validate_mouse_interaction.py .
python -m compileall -q tools tests
godot --headless --path . --import
godot --headless --path . --script res://tests/godot/test_runner.gd
godot --headless --path . --quit-after 8
```

GitHub Actions 使用普通 checkout，不拉取 submodule，并执行 Python 测试、两个仓库验证器、官方 Godot 4.6.3 资源导入、无头玩法测试、主场景启动检查和图形截图验收。

自动测试覆盖：

- 世界尺寸、地图坐标换算和 A* 网格转换
- A* 绕过实体、目标不可达、动态障碍注销和重叠占用计数
- WASD 取消自动靠近、抵达信号和路径清理
- 七种鼠标光标状态、工具锁定、不可达优先级和目标点击分发
- 树木、岩石工具校验、采集次数、单次耗尽和动态碰撞注销
- 掉落物完整转移、部分溢出、背包满保留和出生资源数量
- 枝条/碎石制作石斧/石镐，再经真实交互管理器获得木材/石头的完整闭环
- 相机缩放上下限及世界边界
- Tab、Esc、滚轮、`Ctrl + 滚轮`与数字键输入路由
- 多暂停原因互不覆盖
- 三项玩家资源及 HUD 绑定
- 房屋门口、桥梁、关键路线和出生点可通行性
- 世界模型底座碰撞、唯一实例 ID 和脚底 Y 排序
- 无效玩家位置恢复
- 小地图坐标、标记生命周期和最终 HUD 场景组合
