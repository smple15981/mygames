# Hearthwild 核心玩法垂直切片设计

- 状态：已确认
- 日期：2026-08-04
- 目标版本：首个 15～20 分钟可完整体验的玩法闭环
- 基础：Godot 4.x、纯 2D、现有 `main` 画面与移动原型

## 1. 目标

本阶段把当前“可移动、可观看”的原型推进为一个可完整游玩的垂直切片：

```text
拾取树枝与碎石
→ 制作石斧、石镐
→ 采集木材与石头
→ 制作木剑
→ 击败史莱姆并拾取凝胶
→ 在工作台制作木锄
→ 从农舍旧箱子取得破旧水壶和第一包种子
→ 锄地、播种、浇水
→ 睡觉推进一天
→ 作物成长并最终收获
```

成功标准：新玩家无需阅读外部说明，能在 15～20 分钟内完成上述循环，并理解资源、工具、战斗、制作、种植、时间和存档之间的关系。

## 2. 本阶段范围

### 包含

- 鼠标朝向的近战三段连击
- 90° 前方扇形攻击判定
- 闪避、精力和短暂无敌帧
- 一种基础敌人：草原史莱姆
- 树木、松散碎石、普通岩石三类采集目标
- 地面资源、实体掉落和自动拾取
- 20 格背包，前 5 格直接作为快捷栏
- 随身制作与工作台制作
- 石斧、石镐、木剑、木锄、破旧水壶等首批物品
- 一种作物：月露萝卜
- 昼夜、睡觉、天数和单人菜单暂停
- 教学目标、失败保护、自动保存与读取

### 明确不包含

- 多人联机
- 经济、商店和复杂 NPC 对话
- 多种矿物、多种作物、工具升级树
- 远程武器、魔法、Boss、精英词缀
- 复杂体力劳动消耗、水壶容量或补水
- 建筑摆放、钓鱼、烹饪和大型任务系统

## 3. 操作规则

- `WASD` 或方向键：移动
- 鼠标位置：角色攻击和工具使用朝向
- 鼠标左键：使用当前快捷栏物品
- `1`～`5` 或鼠标滚轮：切换快捷栏
- 空格：闪避
- `E`：交互、打开工作台、旧箱子、床等
- `Tab`：背包与随身制作
- `Esc`：暂停菜单

左键统一规则：

- 空手：低效率徒手采集或拾取交互
- 剑：扇形近战攻击
- 斧：砍伐最近的有效树木
- 镐：开采最近的有效岩石
- 锄：翻整可耕作土地
- 水壶：浇灌最近的已播种农田格
- 种子：种植到最近的已翻整空地
- 食物：播放短使用动作后生效

无有效目标时只播放挥空动作，不产生掉落，不消耗材料。

## 4. 架构

采用模块化组件架构，保留数据驱动扩展能力，不把所有逻辑写入 `PlayerController`。

```text
Player
├── PlayerController       移动与基础朝向
├── PlayerCombat           连击、攻击锁定和命中请求
├── PlayerDodge            闪避、精力、无敌帧
├── ItemUser               当前物品到具体行为的分发
├── Inventory              20 格背包与 5 格快捷栏
└── InteractionDetector    交互对象和目标提示

World
├── TimeManager            时间、天数、菜单暂停、睡觉结算
├── SaveManager            存档、备份、读取和版本迁移入口
├── TutorialDirector       非阻塞式教学目标
├── ResourceNode           树木、碎石和岩石
├── SlimeEnemy             第一种敌人
├── Pickup                 实体掉落和自动吸附
├── FarmCell               农田状态
├── Workbench              高级制作
└── Bed / OldChest         睡觉与水壶教学
```

依赖方向：玩家行为发送请求，目标组件自行决定是否响应。玩家脚本不直接判断具体场景节点名称。

## 5. 数据资源

### `ItemDefinition`

字段：

- `id`
- `display_name`
- `icon`
- `item_type`
- `max_stack`
- `use_cooldown`
- 对应行为数据引用

物品类型：材料、武器、工具、种子、食物、关键物品。

### 武器数据

- 基础伤害
- 攻击距离
- 扇形角度
- 连击段数
- 每段倍率
- 击退强度
- 连击窗口

### 工具数据

- 工具类别
- 工具等级
- 作用距离
- 每次作用强度

### `RecipeDefinition`

- 配方 ID
- 输出物品与数量
- 材料列表
- 制作位置：随身或工作台
- 是否为关键配方

### `CropDefinition`

- 作物 ID
- 生长所需有效浇水日
- 各视觉阶段
- 收获物
- 返还种子概率

## 6. 行为数据流

```text
玩家按左键
→ ItemUser 读取当前快捷栏物品
→ 构造 ActionRequest
→ 按鼠标方向搜索有效目标
→ 目标组件校验类型、距离、冷却和状态
→ 返回 ActionResult
→ 独立反馈层播放动画、粒子、音效、伤害数字和震屏
→ Inventory 或 Pickup 处理产出
```

### `ActionRequest`

至少包含：

- 发起者
- 世界坐标
- 鼠标方向
- 行为类型
- 工具类别和等级
- 伤害、距离和扇形角度
- 唯一动作序号，防止一次挥砍重复结算

### `ActionResult`

至少包含：

- 是否成功
- 命中目标列表
- 实际伤害或采集强度
- 生成掉落列表
- 失败原因枚举
- 建议反馈类型

## 7. 背包与快捷栏

- 背包固定 20 格。
- 前 5 格直接作为快捷栏，不维护第二份物品副本。
- 相同物品优先补充已有堆叠，再使用空格。
- 材料默认可堆叠；工具和关键物品单格存放。
- 背包满时，拾取物停止吸附并保留在地面。
- 数字键或滚轮只改变当前选中索引。
- 水壶、木锄和第一包种子不可丢弃、不可作为材料消耗。
- 关键制作成品在背包满时进入工作台输出槽，不得消失。

单人模式打开背包、制作、对话、商店或暂停界面时，世界时间暂停。未来多人模式改为普通界面不暂停，但本阶段不实现多人规则。

## 8. 制作

### 随身制作

| 物品 | 材料 |
|---|---|
| 石斧 | 树枝 ×3、碎石 ×2 |
| 石镐 | 树枝 ×3、碎石 ×3 |
| 木剑 | 木材 ×4、碎石 ×1 |
| 火把 | 木材 ×1、史莱姆凝胶 ×1 |

### 工作台制作

| 物品 | 材料 |
|---|---|
| 木锄 | 木材 ×5、石头 ×2、史莱姆凝胶 ×1 |
| 简易绷带 | 野草 ×3、史莱姆凝胶 ×1 |

制作界面只展示已解锁配方和接近满足的关键配方。材料不足时显示每种缺口数量。制作事务必须先验证容量和材料，再一次性扣除，避免中途失败造成材料丢失。

## 9. 战斗

### 普通攻击

三段连击：快速横斩、反向横斩、较大范围重击。

首轮平衡值：

- 攻击距离：约 1.75 个逻辑地图格
- 判定角度：90°
- 连击衔接窗口：0.45 秒
- 攻击期间移动速度降低
- 第三段伤害和击退高于前两段
- 一次攻击可以命中扇形内多个敌人
- 同一目标在同一动作序号内只能结算一次

命中反馈与逻辑分离，包括轻微停顿、闪白、击退、粒子、伤害数字和小幅震屏。关闭视觉反馈不会改变伤害结果。

### 闪避与精力

- 精力上限：100
- 每次闪避消耗：40
- 恢复速度：约 28/秒
- 闪避后存在短暂恢复延迟
- 闪避前半段拥有无敌帧
- 有移动输入时朝移动方向闪避；静止时朝鼠标方向
- 精力不足只拒绝闪避，不打断移动或攻击
- 普通攻击、采集和农务不消耗精力

### 草原史莱姆

状态：闲逛、感知、跳跃追击、攻击前摇、冲撞、硬直、返回出生区域、死亡。

规则：

- 攻击前有清晰压缩与闪动提示
- 普通史莱姆约 4～6 次攻击可击倒满血玩家
- 受到攻击会短暂击退，但有控制保护
- 失去玩家后返回出生区
- 死亡必掉史莱姆凝胶，小概率掉种子
- 教学史莱姆参数更弱，且在教学未完成时可重生

### 玩家倒下

- 淡出后回到农舍床边
- 恢复部分生命和全部精力
- 当天时间向后推进一段，不直接进入第二天
- 随机损失当天获得的少量普通材料
- 工具、武器、任务物品、种子和关键材料不丢失
- 地面掉落保留到当天结束

## 10. 采集与掉落

`HarvestableComponent` 统一描述：可接受工具、等级要求、当前耐久、掉落表、反馈和刷新规则。

### 树木

- 空手可缓慢取得少量树枝
- 石斧可正常砍伐
- 命中产生摇晃与叶片粒子
- 耐久归零后掉落木材和树枝
- 树桩本阶段直接消失
- 睡觉后只刷新部分普通树木

### 岩石

- 空手只能处理松散碎石
- 石镐可开采普通岩石
- 具有裂纹阶段和碎石粒子
- 耐久归零后掉落石头

### 地面资源和实体掉落

- 树枝、碎石和野草在固定区域按规则生成
- 玩家靠近后自动吸附
- 掉落物先短暂弹跳，再进入可拾取状态
- 背包满时保留在原地并显示名称
- 睡觉后清理普通无关掉落，关键掉落保留

## 11. 农田与作物

农田状态：

```text
未开垦
→ 已翻地
→ 已播种
→ 当日已浇水
→ 睡觉结算成长
→ 成熟
→ 收获后恢复为已翻地
```

第一种作物为月露萝卜：

- 需要 3 个有效浇水日成熟
- 视觉阶段：种子、幼苗、成长、成熟
- 漏浇不会死亡，只是不累计当天成长
- 成熟后可左键或交互收获
- 收获获得萝卜，并有概率返还种子

破旧水壶：

- 从农舍旧箱子获得
- 与第一包种子同时发放
- 一次浇一格
- 水量无限
- 不可丢弃
- 不具备攻击能力

## 12. 时间、睡觉和暂停

采用混合昼夜制：

- 游戏时间持续流逝
- 白天、黄昏和夜晚平滑改变环境色调与局部灯光
- 夜晚不会强制昏倒
- 玩家可在夜晚继续探索和战斗
- 使用床主动结束当天
- 单人菜单、制作和对话暂停世界

睡觉结算顺序固定为：

1. 锁定输入并淡出
2. 结算已浇水作物成长
3. 清理普通地面掉落
4. 部分刷新采集资源和普通史莱姆
5. 天数加一并重置当日浇水状态
6. 将时间设为早晨
7. 自动保存
8. 淡入并恢复输入

## 13. 教学流程

教学通过屏幕侧边的小目标推进，不使用长篇强制弹窗，也不锁死无关操作。

```text
在农舍醒来
→ 拾取树枝与碎石
→ 制作石斧和石镐
→ 采集木材与石头
→ 制作木剑
→ 击败教学史莱姆
→ 在工作台制作木锄
→ 回农舍打开旧箱子
→ 取得水壶和种子
→ 锄地、播种、浇水
→ 睡觉进入第二天
```

已提前完成的步骤自动跳过。教学状态必须可存档，读取后从当前未完成目标继续。

## 14. 防卡关规则

- 教学区每天保证最低数量的树枝和碎石
- 未拥有斧头时保留至少一个可徒手取得树枝的目标
- 未拥有镐子时保留足够松散碎石
- 教学史莱姆在任务未完成时可重新生成
- 关键制作成品在背包满时进入安全输出槽
- 旧箱子的水壶和种子只能领取一次，领取状态可存档
- 关键物品不可丢弃、不可卖出、不可作为配方材料
- 任何掉落表为空或资源加载失败时记录警告，并使用安全的空结果，不让主循环崩溃

## 15. 存档

自动保存时机：

- 睡觉完成后
- 首次完成种植教学后
- 返回主菜单前

存档内容：

- 存档版本
- 当前天数和时间
- 玩家位置、生命和精力
- 背包全部格子与快捷栏选中索引
- 已解锁或完成的配方状态
- 教学进度
- 关键箱子领取状态
- 树木、岩石和地面掉落状态
- 敌人必要状态
- 农田和作物状态

写入策略：先写临时文件，验证可解析后再替换正式存档；替换前保留上一份有效备份。读取失败时不覆盖损坏文件，先尝试备份，再回退到新游戏并显示明确提示。

## 16. 错误处理

- 缺失物品定义：使用可识别的“未知物品”占位，不删除存档格子
- 缺失配方：隐藏该配方并记录警告
- 行为目标在动作中途失效：返回失败结果，不扣材料、不重复播放奖励
- 背包写入失败：掉落继续留在世界
- 制作事务失败：材料保持原状
- 作物定义失效：农田保留原始数据并停止成长，不清空玩家进度
- 存档版本变化：通过显式迁移函数升级，不在加载函数里散落临时判断

## 17. 测试策略

### 纯逻辑测试

- 堆叠、溢出和背包满
- 快捷栏与背包同一数据源
- 配方材料校验和原子扣除
- 连击窗口与动作序号去重
- 扇形目标筛选
- 精力消耗、恢复和闪避拒绝
- 作物浇水日结算
- 睡觉结算顺序
- 教学步骤自动跳过
- 存档往返、备份和损坏文件回退

### Godot 场景测试

- 玩家左键按当前物品调用正确行为
- 剑可命中多个史莱姆但不会重复命中同一目标
- 斧、镐、锄和水壶不会作用于错误目标
- 背包满时掉落不消失
- 教学史莱姆和最低资源保护能解除卡关
- 睡觉后作物、资源、时间和存档结果一致
- 所有单人菜单正确暂停世界

### CI 冒烟测试

- 无头导入项目
- 启动主场景
- 创建新游戏并执行基础输入
- 打开和关闭背包
- 睡觉结算一次
- 日志中无 `SCRIPT ERROR`、运行时 `ERROR:` 或资源回退警告

## 18. 验收标准

完成本阶段时必须同时满足：

1. 新存档可以从空手开始，不依赖调试指令完成全部闭环。
2. 正常玩家首次完成循环的目标时间为 15～20 分钟。
3. 战斗具有清晰前摇、命中反馈、闪避和失败代价。
4. 背包满、资源不足、教学对象丢失等情况不会让存档永久卡死。
5. 月露萝卜必须经过 3 个已浇水日才成熟。
6. 睡觉会按固定顺序推进世界并完成自动保存。
7. 删除 `.godot` 后从普通仓库下载仍能导入并运行全部素材。
8. 自动测试、验证脚本、Godot 无头导入和主场景冒烟测试全部通过。

## 19. 实施边界

实现应按可独立验证的纵向小步推进，而不是先创建所有空框架。每一步都必须形成可运行结果，并保持现有移动、画面、碰撞和开源素材加载不回退。具体任务拆分将在本设计批准后另写实施计划。
