# Hearthwild 鼠标交互采集 MVP 设计

日期：2026-08-05  
状态：已确认，等待实施计划  
目标分支：`design/mouse-interaction-mvp`

## 1. 目标

在保留现有大地图、WASD 移动、相机缩放、小地图、生命/体力/魔力 HUD、快捷栏、背包和随身制作的前提下，完成第一个最小可玩闭环：

```text
出生
→ 靠近并自动拾取枝条与碎石
→ 制作石斧与石镐
→ 鼠标点击树木或岩石
→ 角色自动绕开障碍靠近目标
→ 持续采集直到资源耗尽
→ 生成木材或石头掉落
→ 靠近自动拾取进入背包
```

本阶段同时修复仍存在的模型穿模、视觉遮挡错误、空气墙、碰撞尺寸与贴图偏移不一致问题。

## 2. 已确认的产品决策

- 操控方式：WASD 手动移动，鼠标负责选择和执行世界交互。
- 自动行动取消：按下任意 WASD 后立即取消自动靠近与持续采集。
- 拾取方式：玩家靠近掉落物后自动吸附并拾取。
- 采集方式：单击资源一次，自动靠近并持续采集到资源耗尽。
- 鼠标样式：状态型原创像素光标，并配合目标描边高亮。
- 起步资源：出生区放置枝条和碎石，先制作石斧、石镐，再采集树木和岩石。
- 自动靠近：使用 32×32 逻辑网格的 A* 寻路。
- 架构：采用职责分离的组件化最小闭环，不把全部逻辑塞进 `WorldLayout`。
- 工具耐久：本阶段不实现。
- 徒手采集：本阶段不允许；缺少正确工具时不移动、不伤害资源。

## 3. 范围

### 3.1 本阶段实现

- 鼠标悬停识别、状态光标和目标描边。
- 点击树木、岩石和交互对象后的目标选择。
- A* 自动靠近、路径重规划和 WASD 取消。
- 树木、岩石资源生命值与工具类型校验。
- 持续采集循环、反馈动画、资源耗尽和掉落。
- 枝条、碎石、木材、石头的地面实体与自动拾取。
- 石斧、石镐制作闭环与现有背包/快捷栏集成。
- 树木、岩石、房屋、围栏、河岸和装饰物的碰撞与 Y 排序修复。
- 自动测试、主场景烟雾测试和图形截图验收。

### 3.2 明确不实现

- 复杂战斗、敌人 AI、Boss、闪避和伤害结算。
- 多人联机与网络同步。
- 完整种植、成长、浇水和收获循环。
- 昼夜、天气、饥饿、温度和生存数值。
- NPC 对话、完整任务系统和剧情。
- 工具耐久、维修、品质和随机词条。
- 动态障碍物群、行为树和通用命令队列。
- 点击地面移动；地面点击不会取代 WASD。

## 4. 总体架构

```text
PrototypeWorld
├── WorldLayout
├── WorldCollisionRegistry
├── WorldPathGrid
├── WorldInteractionManager
│   ├── CursorStateManager
│   └── InteractionTarget Registry
├── Entities (Y Sort)
│   ├── Player
│   │   ├── PlayerController
│   │   ├── AutoMoveAgent
│   │   ├── MouseInteractionController
│   │   ├── ItemUser
│   │   └── Inventory
│   ├── HarvestableResource
│   └── WorldPickup
└── HUD
```

### 4.1 `WorldPathGrid`

职责：

- 根据 `WorldLayoutConfig` 的世界尺寸和 `WorldCollisionRegistry` 的占用矩形构建 32×32 网格。
- 水域、世界边缘、树干、岩石底座、房屋墙体和围栏为不可通行格。
- 门口、桥梁、道路和普通地面保持可通行。
- 为一个目标碰撞矩形计算四周可站立候选格，并选择路径成本最低的终点。
- 资源耗尽后更新相应占用格，不重建整个世界。

### 4.2 `AutoMoveAgent`

职责：

- 保存当前路径、目标和重规划次数。
- 沿路径点给 `PlayerController` 提供移动方向，不直接改写玩家位置。
- 最终移动继续使用 `CharacterBody2D.move_and_slide()`，物理碰撞仍是最后防线。
- WASD 输入、背包打开、暂停、目标失效或点击新目标时立即取消。
- 连续被阻挡时最多重新规划两次；仍失败则停止并反馈“无法到达”。

### 4.3 `MouseInteractionController`

职责：

- 读取鼠标下方的交互目标。
- 管理悬停目标、描边状态和左键点击。
- 判断工具是否匹配、目标是否可达以及当前是否处于 UI 模态状态。
- 点击有效资源后请求 `AutoMoveAgent` 靠近；到达交互距离后启动持续采集。
- 不处理背包数据，不直接修改资源生命值。

### 4.4 `CursorStateManager`

状态：

- `DEFAULT`：原创像素箭头。
- `HARVEST_AXE`：可砍伐树木。
- `HARVEST_PICKAXE`：可开采岩石。
- `PICKUP`：可拾取物。
- `INTERACT`：工作台、门或后续交互设施。
- `UNREACHABLE`：目标无可用路径。
- `TOOL_LOCKED`：目标可识别，但缺少正确工具。

所有光标使用原创像素资源，热点放在图标实际指向点。打开背包或暂停时恢复默认光标并禁止世界点击。

### 4.5 `HarvestableResource`

配置字段：

- 资源类型：树木或岩石。
- 所需工具类型：斧或镐。
- 最大采集生命值。
- 每次有效命中的采集伤害。
- 交互距离。
- 掉落物品 ID、数量范围和掉落偏移。
- 对应碰撞注册 ID。

行为：

- 正确工具命中时扣除生命值。
- 每次命中播放轻微抖动和短暂闪白。
- 生命值归零后注销物理碰撞、路径障碍和交互区域，生成掉落，再删除视觉实体。
- 错误工具不会扣除生命值。

### 4.6 `WorldPickup`

行为：

- 不参与玩家物理阻挡。
- 玩家进入约 30 像素吸附范围后向玩家移动。
- 到达拾取范围时调用 `InventoryModel.add_item()`。
- 成功放入背包后删除实体。
- 背包已满时停止吸附并留在地面，只显示一次“背包已满”。

## 5. 输入与状态优先级

```text
WASD 手动输入
> 背包/暂停模态状态
> 鼠标自动行动
```

### 5.1 取消条件

自动靠近和持续采集在以下情况立即取消：

- 玩家按下任意 WASD 或方向键。
- 玩家点击另一个目标。
- 玩家打开背包。
- 游戏进入暂停。
- 当前目标被删除、耗尽或失效。
- 路径重规划两次后仍失败。

### 5.2 左键行为

- 悬停可采集资源且工具匹配：选中目标并开始自动靠近。
- 悬停资源但工具不匹配：不移动，显示“需要石斧”或“需要石镐”。
- 悬停不可达目标：不移动，显示红色禁止光标。
- 悬停 UI：由 UI 消费输入，不向世界传播。
- 悬停空地：本阶段不执行点击移动。

## 6. 最小资源闭环

### 6.1 出生区固定资源

在玩家安全出生区域附近生成：

- 枝条 × 8。
- 碎石 × 7。
- 可采集小树 × 3。
- 可采集岩石 × 3。

这些数量允许制作石斧和石镐，并保留少量拾取或操作容错。

### 6.2 现有配方复用

- 石斧：3 枝条 + 2 碎石。
- 石镐：3 枝条 + 3 碎石。

制作继续使用现有 `CraftingService` 原子事务：材料不足、配方无效或背包无空间时不错误扣除材料。

### 6.3 采集数值

- 小树：3 点采集生命值，必须装备石斧，耗尽后掉落木材。
- 树丛：5 点采集生命值，必须装备石斧，耗尽后掉落更多木材。
- 普通岩石：4 点采集生命值，必须装备石镐，耗尽后掉落石头。
- 每次采集造成 1 点采集伤害，节奏由当前工具的 `use_cooldown` 控制。
- 工具无耐久，不会在本闭环中损坏。

## 7. 碰撞、脚底锚点与 Y 排序

所有可排序实体统一遵循：

```text
实体根节点位置 = 与地面接触的底部中心
视觉贴图       = 相对根节点向上偏移
物理碰撞       = 只覆盖脚底、树干、岩石底座或建筑基座
交互区域       = 与物理碰撞分离
Y 排序依据     = 实体根节点的全局 Y
```

### 7.1 碰撞层

- Layer 1：房屋、树干、岩石、围栏、河岸等世界实体。
- Layer 2：玩家身体。
- Layer 4：鼠标悬停和交互目标。
- Layer 8：掉落物触发区域。

交互区和拾取区不得参与玩家物理阻挡。

### 7.2 分类修复

#### 树木

- 只阻挡树干与根部，不阻挡树冠透明区域。
- 树丛保留两个独立树干碰撞。
- 玩家经过树冠后方时由 Y 排序自然遮挡。
- 树木耗尽后立即注销碰撞和 A* 障碍。

#### 岩石

- 碰撞只覆盖接地底座。
- 视觉缩放与碰撞尺寸使用同一配置基准校准。
- 不使用整张图集区域作为碰撞范围。

#### 房屋

- 只阻挡墙体、侧边和地基。
- 门口始终可通行。
- 屋顶只负责视觉遮挡，不扩大物理碰撞。
- 农舍和工作间分别维护碰撞配置。

#### 围栏

- 沿底部横梁生成连续碰撞。
- 端点不得留下可钻入模型内部的缝隙。
- 透明上半部分不阻挡玩家。

#### 河流与桥梁

- 非桥梁水域生成连续阻挡。
- 两座桥对应格必须同时从物理碰撞和 A* 障碍中移除。
- A* 与物理世界使用同一份桥梁和水域数据。

#### 装饰物

- 草丛、花朵、光点、粒子和普通地面碎屑不注册实体碰撞。

## 8. 数据流

### 8.1 悬停与点击

```text
鼠标位置
→ WorldInteractionManager 查询 Layer 4
→ InteractionTarget 返回类型、工具要求和范围
→ WorldPathGrid 判断可达性
→ CursorStateManager 更新光标
→ 目标视觉更新描边
```

### 8.2 自动采集

```text
左键点击有效资源
→ MouseInteractionController 设为当前目标
→ WorldPathGrid 选择目标周围安全站立格
→ AutoMoveAgent 计算并跟随路径
→ 进入交互距离
→ 面向目标
→ 按工具冷却持续请求采集
→ HarvestableResource 扣除生命值
→ 资源耗尽
→ 注销碰撞与路径障碍
→ 生成 WorldPickup
```

### 8.3 自动拾取

```text
玩家进入吸附范围
→ WorldPickup 靠近玩家
→ InventoryModel.add_item()
→ 成功：删除掉落物
→ 失败：掉落物保留并停止吸附
```

## 9. 异常处理

- 缺少正确工具：不启动自动移动，不损伤资源。
- 目标不可达：红色禁止光标，点击无副作用。
- 自动移动被阻挡：重新规划最多两次。
- 目标在途中消失：安全取消，不访问已释放节点。
- 背包已满：掉落物不消失。
- 打开背包：取消自动行为，由现有暂停协调器冻结世界。
- UI 截获点击：不传播到世界交互层。
- 路径目标格被动态占用：重新选择候选站立格。
- 资源注销碰撞失败：记录错误并阻止资源节点删除，避免留下隐形墙。

## 10. 测试策略

### 10.1 单元测试

- A* 网格从世界边界、河流和碰撞矩形正确生成。
- 桥梁和门口保持可通行。
- 目标周围候选站立格不会落入碰撞内部。
- WASD 输入会立即取消路径和采集状态。
- 错误工具不能扣除资源生命值。
- 正确工具按冷却持续采集。
- 资源耗尽后注销路径障碍和物理碰撞。
- 背包有空间时拾取成功；背包满时掉落保留。
- 点击新目标会替换旧目标。
- 打开背包后世界点击不生效。

### 10.2 Godot 集成测试

- 玩家能绕过房屋、树木、岩石、围栏和河岸到达资源。
- 玩家不能穿过树干、岩石、墙体、围栏和非桥梁河流。
- 玩家可以通过房屋门口和两座桥。
- 玩家从模型前后经过时遮挡顺序正确。
- 树木和岩石耗尽后原位置可通行。
- 从出生到制作双工具、砍树、挖矿、拾取木材和石头的完整闭环可执行。

### 10.3 回归测试

- `Tab`、`Esc`、数字键 1～5、滚轮缩放和 Ctrl+滚轮切换快捷栏保持正常。
- 小地图、三状态栏、背包、快捷栏和制作 UI 无布局回退。
- 世界尺寸、关键路线和安全出生点验证继续通过。
- Python 契约测试、Godot 无头测试、资源导入和主场景烟雾测试全部通过。

### 10.4 图形验收

截图至少覆盖：

- 专属默认光标和资源光标。
- 资源悬停描边。
- 玩家位于树木、房屋和岩石前后时的遮挡关系。
- 出生区枝条、碎石、小树和岩石分布。
- 木材或石头掉落与自动拾取过程。
- HUD、小地图、快捷栏和背包没有遮挡或重叠。

## 11. 完成标准

本阶段只有在以下条件全部满足时才可称为完成：

1. 玩家能通过靠近自动拾取足量枝条和碎石。
2. 玩家能使用现有制作界面制作石斧与石镐。
3. 点击树木或岩石后角色能通过 A* 绕障碍自动靠近。
4. 按下 WASD 能立即取消自动靠近和持续采集。
5. 正确工具能持续采集并生成对应掉落；错误工具不能采集。
6. 掉落物能自动进入背包，背包满时不会丢失。
7. 树木、岩石、房屋、围栏和河岸不存在可复现的实体穿透或明显空气墙。
8. 前后遮挡符合脚底 Y 排序，不出现整张模型错误覆盖玩家。
9. 原有大地图、小地图、状态栏、背包、快捷栏、制作和缩放功能无回退。
10. 所有自动测试、主场景烟雾测试和图形截图验收通过。
