# Hearthwild 纯 2D 重构设计规格

日期：2026-08-04  
状态：已确认  
取代：`2026-08-04-hearthwild-hd2d-design.md`

## 1. 决策

项目从“3D 环境 + 2D 角色”的混合 HD-2D 路线切换为纯 2D 像素俯视路线。核心原因是减少模型、材质、光照、摄像机和 3D 动画成本，把开发精力集中到玩法闭环。

## 2. 技术方案

- Godot 4.3+ 与 GDScript。
- 640×360 基础视口，近邻过滤，面向 720p/1080p 整数倍放大。
- 32×32 地图格。
- `TileMapLayer` 构建地形。
- `CharacterBody2D` 负责玩家与敌人移动。
- `AnimatedSprite2D` 负责角色动画。
- `Area2D` 负责攻击、交互、采集和触发器。
- `StaticBody2D` 负责建筑、树木、岩石和地图障碍。
- `Camera2D` 跟随玩家。
- 世界实体容器启用 Y 排序。
- `CanvasLayer` 承载 HUD、背包、制作和菜单。

## 3. 首个原型范围

当前重构只交付纯 2D 技术骨架：

1. 32×32 瓦片地图。
2. 农场、道路、河流、森林和洞穴入口的视觉分区。
3. 八方向移动、碰撞、朝向和摄像机跟随。
4. 房屋、树木、岩石、作物、史莱姆与掉落物占位。
5. 开源素材许可证记录。
6. 自动检查禁止 3D 节点重新进入项目。

战斗、种植逻辑、背包、制作、敌人 AI 和存档属于后续独立阶段。

## 4. 美术规则

- 统一使用清晰轮廓、有限色板和近邻过滤。
- 地图格固定为 32×32。
- 常规人物目标尺寸为 32×40 或 32×48。
- 建筑和树木允许跨多个格子。
- 角色脚底作为 Y 排序基准。
- 第一阶段使用原创 SVG 像素占位图，后续可替换为同规格 sprite sheet。
- 第三方素材必须是 CC0、CC-BY、MIT 或其他已审计的开放许可证。

## 5. 组件边界

### PlayerController

只负责输入、速度、碰撞移动和视觉朝向，不处理背包、战斗伤害或任务。

### MovementMath

提供输入归一化、四方向朝向选择和动画名映射，可独立测试。

### PrototypeWorld

只负责地图原型和场景摆放。运行时生成临时瓦片图，后续美术导入后可替换为正式 TileSet，不影响玩家逻辑。

### Repository Validator

检查主场景、视口、纯 2D 节点、TileMapLayer、Camera2D、Y 排序、场景引用和第三方许可证。发现 3D 节点即失败。

## 6. 验收

- 仓库中当前运行代码与场景不含 3D 节点。
- 玩家场景根节点为 `CharacterBody2D`。
- 世界使用 `TileMapLayer`。
- 玩家包含 `AnimatedSprite2D` 与 `Camera2D`。
- 八方向输入的斜向速度不超过直线速度。
- GitHub Actions 测试通过。
- Godot 4.3+ 能导入并运行主场景。
